# Well-structured transition systems

This directory formalises **well-structured transition systems** (WSTS; Finkel and Schnoebelen
2001, Abdulla et al. 2000) generically on top of `LTS`, together with the backward coverability
algorithm and its termination.

## Design

- **`StronglyMonotone lts`** is a class on an `LTS State Label` with `[Preorder State]`: if
  `s₁ ≤ s₂` and `s₁ -μ→ s₁'`, then `s₂ -μ→ s₂'` for some `s₂' ≥ s₁'`. It needs no well-quasi-order,
  and already gives monotonicity of multistep transitions and reachability, upper-set closure of
  the backward iteration, and the soundness half of backward coverability.
- **`WSTS lts`** extends `StronglyMonotone lts` with Mathlib's `WellQuasiOrderedLE State`. It is
  needed for termination of the backward iteration and for decidability. The weaker
  reflexive/transitive monotonicity is not formalised. Unlabelled steps are handled through
  `LTS.UnlabelledTr`.
- **Backward coverability** works with upper sets. `predSet`, `backStep` and `backSeq` are the
  predecessor set, one backward step and the backward iteration. The key fact is that ascending chains of upper sets in a well-quasi-order stabilise
  (`exists_stabilises`), which gives `exists_backSeq_fixpoint`.
- **Effective pred-basis.** `IsPredBasis lts pb` says that `pb : Finset State → Finset State`
  computes a basis of the predecessors of the upper set generated by a finite set. Iterating `pb`
  (`basisSeq`) and testing stabilisation by a finite check (`Stable`, searched with `searchIter`)
  gives `decidableCoverable`: coverability is decidable for a WSTS with decidable `≤`, decidable
  equality, and an effective pred-basis, and the procedure can be evaluated by `decide`. This is
  the abstract decidability theorem of Abdulla et al.; the oracle is a hypothesis, not computed in
  general.
- **Instances.** Vector addition systems with states (control state plus
  counters, configurations ordered by equal control state and pointwise counters) are WSTS in
  `Examples/VASS`, and `Examples/VASSCoverability` constructs a pred-basis, so that coverability is
  decidable for VASS with finitely many rules.

## Contents

| File | Contents |
|------|----------|
| `Basic` | the classes `StronglyMonotone` and `WSTS`, monotone reachability, `Coverable` |
| `Coverability` | `predSet`, `backStep`, `backSeq`; stabilisation of upper-set chains; termination of the backward iteration |
| `Decidability` | finite bases, effective pred-basis, `decidableCoverable` |
| `InfiniteRuns` | an infinite run has an increasing pair; a state starts an infinite run iff it reaches a state that reaches a larger one |
| `Unboundedness` | in a finitely branching system on a well-quasi-order, infinitely many reachable states give a pumping pair `s₁ < s₂` (König with the well-quasi-order; the converse fails in general) |
| `Examples/VASS` | VASS and their configurations are a WSTS |
| `Examples/VASSCoverability` | pred-basis of a VASS, decidable coverability |

## Plans and notes

- Not yet formalised: the Karp–Miller coverability tree and the clover (completion) for WSTS with
  a completion, forward coverability algorithms, the converse of the pumping criterion for
  strict pumps, reflexive/transitive monotonicity,
  decidability of other properties (inevitability, simulation preorders), and WSTS in the
  literature such as lossy channel systems and broadcast protocols.
- `decidableCoverable` searches with `searchIter`
  ([`Search`](../../Foundations/Data/Search.lean)), so it reduces under `decide`.
